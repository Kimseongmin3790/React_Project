# 🎮 GClip – 게임 하이라이트 공유 SNS

![Main Feed](/images/page-main.png)
게임 스크린샷·하이라이트 클립을 올리고 공유하는 **게임 특화 SNS 서비스**입니다.  
유저는 자신이 플레이한 게임의 멋진 순간을 업로드하고,  
태그·게임·탐색 탭을 통해 다양한 클립을 발견할 수 있습니다.

---

## 🧱 Tech Stack

| 영역 | 기술 |
|------|------|
| Frontend | React, React Router, Context API, MUI(Material UI) |
| Backend | Node.js (Express) |
| DB | MySQL |
| 실시간 | socket.io |
| 기타 | JWT 인증, RAWG Games API(게임 목록/정보) |

---

## ⭐ 주요 기능

### 1. 메인 피드

게임별 하이라이트 게시글(이미지/영상) 피드
![Feed Main](/images/feed-main.png)
- **기능**
  - 좋아요 / 북마크 / 공유(링크 복사)
  - 댓글 작성 (기본 댓글, 대댓글/멘션/댓글 좋아요 고도화 예정)
  - 게임 필터 (검색형 드롭다운으로 게임 선택)
- **UI**
  - 인스타그램 스타일 카드 레이아웃
  - 유저 아바타/닉네임, 게임 이름, 업로드 날짜, 좋아요/댓글 수 표시
  - 캡션이 길면 ‘더보기’ 버튼으로 상세 모달 이동
- **기타**
  - 피드 카드를 클릭하면 **게시글 상세 모달(PostDetailDialog)** 오픈  
  - 해시태그 `#태그` 자동 추출 및 태그 피드와 연동
    ![Feed Detail](/images/page-detail.png)

### 2. 게시글 작성 (CreatePostDialog)

사이드바의 **글 쓰기 버튼** 클릭 시 모달로 게시글 작성
![Feed write](/images/page-write.png)
- **기능**
  - 게임 선택 (검색 가능한 드롭다운)
  - 캡션 입력 + 해시태그 인식
  - 이미지 여러 장 업로드
  - 동영상 1개 업로드
  - 업로드 후 메인 피드 자동 새로고침
- **UI**
  - MUI Dialog 기반 모달
  - 이미지/영상 파일 선택 영역 + 프리뷰
  - 유효성 검사 (게임 필수, 미디어 최소 1개 이상 등)

---

### 3. 검색 (Search)

상단 헤더 검색창에서 **통합 검색**
![search page](/images/page-searchResult.png)
- **검색 대상**
  - 유저 (닉네임/아이디)
  - 피드(게시글)
  - 태그
  - 게임
- **UI**
  - 탭 구성: `통합 / 유저 / 피드 / 태그 / 게임`
  - 유저 카드 클릭 시 → 해당 유저 프로필 페이지 이동
  - 태그 클릭 시 → 태그 피드로 이동 (`/tags/:tagName`)
  - 게임 클릭 시 → 메인 피드에서 해당 게임으로 필터링

---

### 4. 게임 랭킹 (인기 TOP 10 게임)

최근 기간 기준으로 **인기 게임 TOP 10**을 보여주는 페이지
![top10game page](/images/page-top10game.png)
- **지표**
  - 게시글 수
  - 누적 좋아요 수
  - 누적 댓글 수
  - 위 지표를 조합한 점수(score)로 랭킹 계산
- **UI**
  - 순위/게임명/게시글·좋아요·댓글 수 표시
  - LinearProgress를 활용한 점수 막대 그래프
  - 각 게임 카드에 “이 게임 피드 보기” 버튼  
    → 메인 피드로 이동하며 해당 게임 필터 자동 적용
  - (RAWG API에서 가져온 게임 썸네일도 함께 표시)

---

### 5. 탐색 탭 (Explore)

새로운 클립과 태그, 게임을 발견할 수 있는 **탐색 페이지**
![explore page](/images/page-explore.png)
- **섹션 구성**
  1. **인기 태그**
     - 최근 N일 기준 사용량이 많은 태그 TOP N
     - `#태그명 · 게시글 수` 형태의 Chip 리스트
     - 클릭 시 → 태그 피드로 이동
  2. **최근 많이 올라오는 게임**
     - 최근 N일 동안 게시글이 많이 올라온 게임 목록
     - 게임 썸네일 + 게시글 수
     - “이 게임 피드 보기” 버튼으로 메인 피드 필터 연동
  3. **랜덤 추천 클립**
     - 랜덤으로 뽑은 하이라이트 그리드
     - 썸네일 클릭 시 → 상세 모달(PostDetailDialog) 오픈

### 6. 실시간 채팅

socket.io 기반 **실시간 채팅 기능**
![page chat](/images/page-chat.png)
- **기능**
  - 게임별 채팅방
    - 게임 선택 → 해당 게임 전용 채팅방 입장
  - 1:1 DM
    - 유저 검색 후 DM 방 생성/입장
  - 방별 안읽은 메시지 수 표시
  - 최근 메시지 도착 시 상단 알림 박스로 “이 방으로 이동” 버튼 제공
![chat UI](/images/page-chatUI.png)
- **UI**
  - 좌측: 게임 선택 / DM 대상 검색 영역
  - 우측: 채팅 메시지 리스트 + 입력창
  - 말풍선 정렬(내 메시지 오른쪽, 상대 왼쪽)
  - 날짜/시간 포맷 (오늘은 시간만, 그 외는 날짜+시간)

### 7. 프로필 / 마이페이지

유저의 활동과 통계를 보여주는 **프로필 페이지**
![my page](/images/page-mypage.png)
- **기능**
  - 프로필 정보: 아바타, 닉네임, 소개(bio)
  - 팔로우/팔로잉/팔로워 수
  - 해당 유저가 올린 클립 그리드
  - 본인 프로필 편집 (닉네임, 소개, 비밀번호, 아바타 변경)
- **UI**
  - 상단 프로필 카드 + 하단 게시글 그리드(인스타 스타일)
  - 그리드 카드 클릭 시 게시글 상세 모달 오픈

### 8. 해시태그 시스템

캡션에서 `#태그` 자동 추출 → 태그 DB와 매핑
![page tag](/images/page-tag.png)
- **동작 흐름**
  - 글 작성/수정 시 캡션을 파싱해 태그 목록 추출
  - `tags`, `post_tags` 테이블에 Insert/Sync
  - 태그 페이지(`/tags/:tagName`)에서 해당 태그가 포함된 게시글만 조회
- **활용**
  - 탐색 탭 인기 태그 섹션
  - 추후 태그 기반 추천, 검색 고도화에 사용

### 9. 댓글 고도화

기본 단일 댓글에서 확장해서, 인스타그램/X 스타일의 **소셜 댓글 시스템**으로 고도화
![page comments](/images/page-comments.png)
- **스레드형 댓글 구조 (대댓글)**
  - `post_comments` 테이블의 `parent_comment_id`를 이용해 **최상위 댓글 + 대댓글 구조**를 구현
  - UI에서는 들여쓰기 형태로 대댓글을 표시해, 대화 흐름을 직관적으로 확인할 수 있습니다.

- **댓글 좋아요**
  - 각 댓글에 **좋아요(Like)** 기능을 추가해, 공감이 많이 받은 댓글을 한눈에 확인 가능
  - 댓글 작성자는 좋아요를 받을 때마다 `user_stats.received_comments` / EXP가 증가하며,
    특정 조건을 만족하면 댓글 관련 **업적(Achievement)** 이 해제됩니다.

- **유저 멘션(@username)**
  - 댓글 입력 시 `@username` 형태로 다른 유저를 멘션할 수 있습니다.
  - 백엔드에서 댓글 내용을 파싱해 `@username` 토큰을 분석 후:
    - 멘션된 유저에게 `COMMENT_MENTION` 타입 **알림(notification)** 생성
    - 실시간 WebSocket(`notify:new`) 이벤트로 상단 헤더 알림 배지 + 드롭다운에 표시
    - 멘션된 유저의 `mentioned_count` 및 관련 업적(`FIRST_MENTIONED` 등) 갱신
  - 프론트에서는 `CommentRichText` 컴포넌트가 댓글 내용을 파싱해서:
    - `@username` → **파란색 텍스트 + 클릭 가능한 링크**로 렌더링
    - 클릭 시 해당 유저의 프로필 `/users/:username` 페이지로 이동

- **댓글 작성자/멘션 업적 연동**
  - 댓글을 처음 남기거나, 특정 개수 이상 남기거나, 다른 유저를 처음으로 멘션하는 경우 등
    **댓글/멘션 활동을 기반으로 업적 시스템과 연동**
  - 업적 달성 시 상단에서 **Achievement Toast**가 떠서, 사용자가 자신의 성장/진행 상황을 바로 인지할 수 있습니다.

### 10. 유저 레벨 & 업적

`user_stats`, `achievements`, `user_achievements` 테이블 기반
![page achievements](/images/page-achievements.png)
- **경험치/레벨**
  - 게시글 작성, 좋아요/댓글을 받았을 때 EXP 누적
  - EXP에 따라 자동 레벨 계산 (`level = floor(exp / 100) + 1`)
  - 상단 헤더 / 마이페이지에서 레벨과 진행도 Progress Bar 표시 예정
- **업적**
  - 예: 첫 글 작성, 좋아요 10개 이상 받기, 특정 게임 클립 많이 올리기 등
  - 조건 만족 시 `user_achievements`에 해금 기록 저장 및 알림

## ✨ 프로젝트 후기

- **좋았던 점**
  - 개인적인 취미인 게임을 기반으로 사이트를 만들어서 좀 더 집중할 수 있었던 것 같음
  - 이전에 배웠던 spring이랑은 다른 방식으로 사이트를 만드는것이 재미있었음
  - React의 장점과 단점에 대해 잘 알수있던 프로젝트였음

- **아쉬웠던 점 / 고쳐야할 점**
  - 프로젝트의 기간이 짧아서 설계가 미흡하게 시작되다 보니 중간에 테이블 및 컬럼이 추가되며 코드가 통일되지 않고 보기 좋지 않게 됨
  - 프로젝트 초기에 기능을 구현 해야 겠다고 생각해 놓고 나중에 기능을 수정하다 보니 컴포넌트화 했으면 좋았을 것 같은 반복적인 코드들이 많이 보임. 다음에는 초기 설계때 컴포넌트화 해야 할 기능들을 정리하면 좋을 것 같음
  - 같은 기능을 사용하는 페이지들은 같은 코드를 쓰는게 좋은데 파일이 늘어나며 같은 기능을 다른 변수를 사용해서 구현하면서 코드가 복잡해지게 됨. 페이지/파일을 만들 때 동일한 기능을 하는 기술들은 미리 통일 시켜두면 좋을 것 같음
